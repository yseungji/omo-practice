# omo-practice

OMO 1차 사전과제 - 개발환경 세팅 및 화면 설계 분석

## 프로젝트 소개

해외로 진출할 때 어디로 가면 좋을지 추천해주는 서비스입니다.
AI 자연어 검색으로 목적·예산·지역·언어·치안 조건을 해석해 도시를 추천하고,
선택한 도시 기준으로 출국 준비 로드맵과 서류 체크리스트를 자동 생성합니다.

## 기술 스택

| 분류 | 기술 |
|------|------|
| 프레임워크 | React + Vite |
| 스타일링 | Tailwind CSS |
| 상태관리 | Zustand |
| 라우팅 | React Router v6 |
| 패키지 매니저 | pnpm |

## 폴더 구조

```
src/
  components/   # 공통 컴포넌트
  pages/        # 페이지
  store/        # Zustand 스토어
  hooks/        # 커스텀 훅
```

## 화면 구조

| 페이지 | 경로 | 주요 기능 |
|------|------|---------|
| 탐색 탭 | `/` | AI 자연어 검색, 목적 선택, 필터, 도시 카드 목록 |
| 내 홈 탭 | `/home` | 출국 준비 로드맵, 예산 계획, 진행률 |
| AI 리포트 모달 | - | 도시 상세 정보, AI 질문 검색, 정량 스탯 |
| 도시 비교 | - | 최대 3개 도시 비교 |
| 로드맵 팝업 | - | 태스크별 서류 체크리스트 |
| 설정 | `/settings` | 이용약관, 개인정보 처리 방침 |

## 상태 관리 (Zustand)

| 상태 | 설명 |
|------|------|
| myCity | 선택한 도시 |
| compareList | 비교함 도시 목록 (최대 3개) |
| activePurpose | 워홀 / 교환학생 / 인턴십 |
| selectedCountry | 선택한 국가 |
| briefingData | AI 검색 결과 |
| user | 로그인 유저 정보 |

## 개발환경 세팅

```bash
# 패키지 설치
pnpm install

# 개발 서버 실행
pnpm run dev
```

## Git 브랜치 전략

```
main  : 배포용 최종 완성본
dev   : 개발 통합 브랜치
feature/기능명 : 기능별 작업 브랜치
```

## 커밋 메시지 컨벤션

| 타입 | 설명 |
|------|------|
| feat | 새로운 기능 추가 |
| fix | 버그 수정 |
| style | 스타일 변경 |
| refactor | 코드 리팩토링 |
| chore | 설정 변경 |
